2 · Optimization recommendations Sample data

Each recommendation is computed with the Model Calculator using verified list prices. Green dollar figures are savings if you act on the recommendation (monthly, with the yearly total and the before → after monthly cost). Risks have no dollar value, but they block attribution and control. The Preliminary Findings tab rolls these up into the score, the top savings, the risks to close and the Recommended Engagement.

Before adding new endpoints, list every AI workflow, who owns it, which identity it runs as, and what it costs per completed task. Total Cost of AI (TCA) = tokens + compute/hosting + people/ops + governance/observability + idle agent compute.i

4 · Switch providers: same workflow, seven ways to run it

Move one workflow across the lineup WWT clients see: Anthropic Claude, OpenAI on Azure, Google Gemini, NVIDIA Nemotron, Meta Llama (on AWS Bedrock), Mistral, and an open-weight / self-hosted option. See cost per task, monthly and annual cost, the change versus today, what you gain or lose, and the one-time cost to migrate. Model choice is a governance decision, not just a procurement line item.

Green = cheaper or a gain versus the current model; red = more expensive or a loss. Migration cost and payback use editable assumptions (re-testing prompts, re-running evals). Quality is not priced here: run your own evals before switching.

6 · Sources & assumptions

Editable assumptions (not verified; replace with client data)

All company data is sample/fictional. People, hosting, governance and migration figures are assumptions for illustration. Self-hosted GPU rate is an assumption, not a quote.

Model prices (USD per 1M tokens, list price, standard tier) · each row shows when it was last checked

OpenAI models are priced on Azure OpenAI Global Standard, which equals OpenAI's direct list price per token. NVIDIA Nemotron and Meta Llama are priced on AWS Bedrock on-demand (Standard tier, US regions); NVIDIA publishes no per-token price of its own. Mistral uses Mistral's official API prices. Excludes cache-write surcharges, long-context surcharges (GPT-6 long prompts; Claude Haiku 5.5 above 100K), regional/data-residency uplifts (Azure US Data Zone +10%, OpenAI +10%, Anthropic US-only 1.1×, Bedrock non-US regions), Bedrock Priority tier and tool fees. All sample tasks stay under those thresholds. Prices change often; re-check before any client use.
